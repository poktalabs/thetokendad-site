# mirroring the zone's settings). When that sync is on, it already carries a
# `User-agent: * / Allow: /` group; repeating it here produced two groups for
# the same user-agent, which the spec leaves undefined.
#
# So this file declares only what the managed block never does: where the
# sitemap is. A robots.txt with a Sitemap line and no rules is valid and fully
# permissive (absence of a rule means allowed), so it stays correct whether the
# managed block is on or off. As of 2026-09-27 it is off: AI crawlers are
# allowed per crawler at the edge (see the workstream STATUS for the list).
